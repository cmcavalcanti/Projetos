Esse código refere-se a agenda 8 DS1  - programa “pesquisa de satisfação” com as variáveis referentes as opiniões: excelente, bom e ruim; e para coletar essa informações foram criadasas as variéveis nome e idade para inserir as informações do entrevistados. Foi usada a estrutura de repetição “while”, e dentro dela a estrutura de condição “if, elif e else” para que o usuário possa informar quantos entrevistados desejar e que eles possa expressar a opinião, e o sistema vai aceitar os dados enquanto as estruturas de repetição e de condição forem verdadeiras (while True).
